WINTER ARC — 56 DAYS

Файлы:
- index.html — приложение
- manifest.webmanifest — настройки установки на главный экран
- sw.js — кеширование оболочки приложения

Как пользоваться:
1. Открой index.html в браузере для тестирования. Данные сохраняются локально в этом браузере.
2. Для установки как полноценного PWA на iPhone приложение должно быть размещено на HTTPS-хостинге (например, GitHub Pages / Netlify).
3. После публикации открой HTTPS-ссылку в Safari → Поделиться → На экран «Домой».

Важно:
- Приложение не подключается напрямую к Apple Health/Watch; шаги и активные калории вводятся вручную.
- Данные хранятся локально на устройстве/в браузере. Используй «Экспортировать мои данные» для резервной копии.
- КБЖУ — ориентировочная оценка по формуле Миффлина—Сан Жеора. Не медицинское назначение.
- Прогноз цикла приблизительный.
- Массажная схема носит общий ознакомительный характер. Не массируй болезненные/воспалённые участки и не используй сильное давление.
- Для надёжной офлайн-работы и установки требуется HTTPS-хостинг.
