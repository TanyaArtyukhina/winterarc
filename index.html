Gentle body care

Схема направлений для мягкого самомассажа
🌿
Это упрощённая схема поверхностных направлений для лёгких поглаживаний, а не медицинская инструкция по лимфодренажу. Давление должно быть очень мягким, без боли и синяков. Массаж не «подтягивает» кожу и не удаляет жир, но может быть приятной частью ухода.
Засчитается привычка «Body massage»
Не делай массаж при болезненности, воспалении, повреждении кожи, необъяснимом отёке или подозрении на тромбоз. При заболеваниях лимфатической/сосудистой системы сначала обсуди технику со специалистом. Для сухой щётки используй только лёгкое давление, не по раздражённой коже.
